Codex Auto Proxy Repair v1.2.0

English
Open the EXE, or fully extract the script archive and run Start-Script.cmd.
Choose your language at the top. The first launch follows your Windows UI language;
unsupported languages default to English. Your choice is remembered locally.
Enable a manual Windows HTTP system proxy, then scan or choose one repair action.
For connection repair, save your work and exit Codex normally before launching it.
This utility targets specific proxy inheritance / Store access issues, not every
connection problem. Verify with a real message and your Dots device list.
Windows-generated errors and system permission prompts follow your Windows language.

Scope / privacy
Windows 10/11 x64; healthy official Store package; manual HTTP system proxy.
PAC/WPAD, credentialed proxies and unsupported protocols are outside this tool's scope.
No global proxy, permanent environment, model, account or device authorization changes.
Store permission changes require Windows administrator approval and apply only to Store.
Only permissions newly added and recorded by this tool can be undone by it.
Diagnostics are saved locally with a whitelist; no upload, chat text, tokens or raw logs.
The release EXE is unsigned; no self-signed trust certificate is installed.
Another PC has not been physically tested. See SHA256SUMS.txt and LICENSE.txt.
